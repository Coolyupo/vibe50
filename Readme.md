# Vibe Fifty Japanese

## 1. 專案簡介

建立一個純ＵＩ遊戲網站

## 2 功能介紹

1. 見面有一個可以選擇平假名（含清音 濁音 半濁音 拗音） 與片假名  的選項功能
然後會有一個互動視窗遊戲如下

- 平假名
    問題：隨機跳出任一個平假名
    使用者輸入對應的羅馬拼音 
    如果正確就顯示正確 自動進入下一題
    如果錯誤就顯示錯誤 維持在這一題等到使用者輸入到正確為止

- 片假名
    問題：隨機跳出任一個片假名
    使用者輸入對應的羅馬拼音 
    如果正確就顯示正確 自動進入下一題
    如果錯誤就顯示錯誤 維持在這一題等到使用者輸入到正確為止
